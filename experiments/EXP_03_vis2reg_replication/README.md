# EXP_03: Vis2Reg Replication

Replication of the MICCAI 2026 paper:
**"Vis2Reg: Visibility-Aware Landmark-Free Geometric 3D–2D Registration for Liver Laparoscopy"**

This folder is completely self-contained. It contains the full model core, configs, requirements, and test scripts.

## Quick Smoke Test (Local or Kaggle)

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Run Phase 1 smoke test
python test_smoke.py
```
